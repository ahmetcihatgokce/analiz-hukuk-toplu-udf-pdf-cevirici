# Analiz Hukuk Toplu UDF PDF Çevirici

Bir klasördeki UDF belgelerini Windows üzerinde topluca PDF’ye dönüştürür. Dönüştürme, bilgisayarınızdaki UYAP Doküman Editörü’nün PDF motoruyla yapılır.

[Windows için 1.01 sürümünü indir (ZIP)](https://github.com/ahmetcihatgokce/analiz-hukuk-toplu-udf-pdf-cevirici/releases/download/v1.01/Analiz-Hukuk-Toplu-UDF-PDF-Cevirici-1.01.zip)

## Kullanım

1. ZIP dosyasını çıkarın ve `Analiz-Hukuk-Toplu-UDF-PDF-Cevirici.exe` dosyasını çalıştırın.
2. UDF dosyalarının bulunduğu klasörü seçin.
3. **PDF’ye dönüştür** düğmesine basın.

PDF’ler seçilen klasörün içindeki `PDF-UYAP` klasörüne, kaynak dosya adları korunarak kaydedilir. Aynı adlı PDF varsa atlanır.

Windows, UYAP Doküman Editörü ve Java 8 gerekir. Belgeler bilgisayarınızda işlenir. Elektronik imzalı belgelerin özgün UDF dosyasını saklayın.
